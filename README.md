## What I do

* **Parametric CAD in code.** Every dimension is a named variable, so one number change rebuilds the whole part.
* **Design for the printer.** Parts are modelled in their print orientation, with fits, tolerances and layer direction worked out up front.
* **Multi part and multi colour.** Snap fits, captive hardware, engraved text and two colour inlays.
* **Freelance design work.** Custom parts delivered to clients as source files, ready to print.

## AI agent (private)

A hybrid system built in Python with machine learning libraries and an LLM API. It reads existing OpenSCAD source files and generates new parts on request, and I use it in my own design workflow.
